# 基板上の LED を 0.5 秒間隔で点滅
from machine import Pin
from time import sleep

led = Pin("LED", Pin.OUT)

while True:
    led.value(1)
    sleep(0.5)
    led.value(0)
    sleep(0.5)

About

実機が先

第1回はオンボードLEDと内蔵温度センサから入ります。配線の前に、書き込みと実行の流れを手で覚えます。

半田付けなし

Pico W はピンヘッダー実装済み。BME280 と OLED はジャンパーでつなぎます。SDA/SCL は GP8 / GP9 で統一です。

クラウドまで

第4回で Wi-Fi に接続し、Render サーバーへ温度・湿度・気圧を送ります。画面で自分の計測を確認して終了します。

Curriculum

全4回のカリキュラム

教材コードは MicroPython 統一です。CircuitPython は使いません。

  1. 第1回

    Thonny ではじめる / LED と内蔵温度

    UF2 の確認、インタープリター設定、シェルで print('はんなり')。 基板LEDの点滅と、RP2040 内蔵温度センサの表示。

    • 01_LED点滅 / main.py
    • 01_温度測定 / main.py
  2. 第2回

    I2C と BME280

    配線図どおりにセンサーをつなぎ、I2C スキャンで 0x76 を確認してから温度・気圧・湿度を測ります。

    • MODE = "scan" でアドレス確認
    • MODE = "measure" で計測
  3. 第3回

    OLED に出す

    同じ I2C バスに SSD1306 を追加。0x3C を確認し、温湿度・気圧を画面に出します。

    • bme280.py / ssd1306.py を Pico へ保存
    • MODE = "oled" で表示
  4. 第4回

    Wi-Fi と Render サーバー

    ルータへ接続し、固定データでクラウドを確認したあと、BME280 の実測値を送ります。

    • Wi-Fi 接続 / I2C スキャン
    • Render サーバーへ固定データ → 計測送信

FAQ

よくある質問

プログラミング未経験でも大丈夫ですか？

大丈夫です。第1回は Thonny のシェルから始め、用意したコードを Pico に保存して動かします。書き換えは少しずつ増やします。

はんだ付けは必要ですか？

キットの Pico W、BME280基板、OLED基板はピンヘッダー実装済みです。BME280基板、OLED基板とはジャンパー接続です。

CircuitPython ですか？

MicroPython (Raspberry Pi Pico) を使います。

自分の Wi-Fi が必要ですか？

第1〜3回は不要です。第4回だけ SSID とパスワード、Render サーバーの URL が必要になります。
